# EP.1 — Prompts (ก๊อปวางทีละช็อต)

ขั้นตอนต่อช็อต: (1) เจนภาพใน Gemini ด้วย IMAGE prompt + แนบรูปอ้างอิงตามคอลัมน์ "แนบ" → (2) เลือกภาพที่ดีที่สุด → (3) ใน Flow ใช้ภาพนั้นเป็นเฟรมเริ่ม + วาง VIDEO prompt

## ช็อต 1 · 8 วิ · Close-Up, eye level
**แนบ:** REF-ฝน, LOC-ร้านมาม่า

**IMAGE (Nano Banana)**
```
ภาพถ่ายจากกล้อง DSLR อัตราส่วน 9:16, Close-Up, eye level:
ฝน: หญิงไทยอายุ 23 ปี ใบหน้ากลม แก้มอิ่ม ตาสองชั้นกลมโต คิ้วโค้งธรรมชาติ จมูกเล็ก ริมฝีปากอิ่มสีชมพูธรรมชาติ ผิวขาวอมเหลือง ผมดำยาวประบ่ามัดหางม้าสูง มีปอยผมข้างหูซ้าย รูปร่างเล็กสูงประมาณ 158 ซม. มีลักยิ้มแก้มขวา สวมเสื้อโปโลสีแดงเลือดหมู ผ้ากันเปื้อนสีเหลืองมัสตาร์ด ป้ายชื่อ "ฝน"
(ใช้ภาพอ้างอิงที่แนบ หน้าเดิมทุกจุด)
การกระทำ: ยืนนิ่งหลังเคาน์เตอร์ น้ำซุปมาม่าสีส้มกระเซ็นเปื้อนผ้ากันเปื้อนและแก้ม น้ำตาคลอ
สีหน้า/อารมณ์: ช็อก เจ็บใจ กลั้นน้ำตา
สถานที่: ร้านมาม่า DIY ขนาดเล็กในห้างสรรพสินค้า ผนังโทนแดง-เหลือง ป้ายร้านเหนือเคาน์เตอร์ ผนังเพ็กบอร์ดแขวนซองมาม่าหลากสีเต็มผนัง ตู้แช่ท็อปปิ้งกระจก เตาไฟฟ้าวางเรียงบนเคาน์เตอร์ไม้ หม้อทองเหลืองด้ามคู่ โต๊ะไม้กับเก้าอี้สีเหลืองมัสตาร์ดและเขียวมะกอก โคมไฟห้อยสีแดงและเหลือง แสงไฟวอร์มไวท์สว่างทั่วร้าน ช่วงเย็น ลูกค้านั่งเต็ม
แสง: แสงไฟวอร์มไวท์จากด้านหน้า, ระยะชัดตื้น พื้นหลังเบลอเล็กน้อย
[Negative: 2D, 3D render, cartoon, low quality, plastic skin, airbrushed skin, extra fingers, deformed hands, text, subtitles, watermark, logo]
```

**VIDEO (Flow / Veo)**
```
Static shot: ยืนนิ่งหลังเคาน์เตอร์ น้ำซุปมาม่าสีส้มกระเซ็นเปื้อนผ้ากันเปื้อนและแก้ม น้ำตาคลอ
(พูดเป็นภาษาไทย) (ฝน: เสียงผู้หญิงอายุ 23 โทนสดใส พูดเร็วเล็กน้อย ร่าเริง ติดหยอกล้อ เสียงสั่นเวลาเสียใจ) "คุณทำแบบนี้ทำไมคะ…"
อารมณ์: ช็อก เจ็บใจ กลั้นน้ำตา, เสียงบรรยากาศ: เสียงชามแตกที่เพิ่งจบ เสียงร้านเงียบลงทันที
[ไม่มีเพลง ไม่มีข้อความ ไม่มีซับไตเติล ไม่มีเอฟเฟกต์ ไม่มีกราฟิก ไม่มีการตัดต่อ]
```

## ช็อต 2 · 9 วิ · Wide Shot, eye level
**แนบ:** REF-เต้, LOC-ร้านมาม่า

**IMAGE (Nano Banana)**
```
ภาพถ่ายจากกล้อง DSLR อัตราส่วน 9:16, Wide Shot, eye level:
เต้: ชายไทยอายุ 24 ปี ใบหน้ารูปไข่ กรามชัดเล็กน้อย ตาชั้นเดียวเรียวยาว คิ้วตรงหนาปานกลาง จมูกโด่งเล็ก ริมฝีปากบาง ผิวสีน้ำผึ้ง ผมดำตัดสั้นรองทรงด้านข้าง ด้านบนยาวเล็กน้อยปัดไปทางขวา รูปร่างผอมสูงประมาณ 178 ซม. มีไฝเล็กใต้ตาซ้าย สวมเสื้อยืดสีดำ ผ้ากันเปื้อนลายทางสีเขียวขี้ม้า-ขาว ป้ายชื่อ "เต้" ที่อก
(ใช้ภาพอ้างอิงที่แนบ หน้าเดิมทุกจุด)
การกระทำ: เต้กำลังแขวนซองมาม่าขึ้นผนังเพ็กบอร์ดอย่างตั้งใจ ร้านคึกคัก ลูกค้านั่งเต็มโต๊ะ
สีหน้า/อารมณ์: ตั้งใจทำงาน อารมณ์ดี
สถานที่: ร้านมาม่า DIY ขนาดเล็กในห้างสรรพสินค้า ผนังโทนแดง-เหลือง ป้ายร้านเหนือเคาน์เตอร์ ผนังเพ็กบอร์ดแขวนซองมาม่าหลากสีเต็มผนัง ตู้แช่ท็อปปิ้งกระจก เตาไฟฟ้าวางเรียงบนเคาน์เตอร์ไม้ หม้อทองเหลืองด้ามคู่ โต๊ะไม้กับเก้าอี้สีเหลืองมัสตาร์ดและเขียวมะกอก โคมไฟห้อยสีแดงและเหลือง แสงไฟวอร์มไวท์สว่างทั่วร้าน ช่วงเย็น ลูกค้านั่งเต็ม
แสง: แสงไฟวอร์มไวท์สว่างทั่วร้าน, ระยะชัดตื้น พื้นหลังเบลอเล็กน้อย
[Negative: 2D, 3D render, cartoon, low quality, plastic skin, airbrushed skin, extra fingers, deformed hands, text, subtitles, watermark, logo]
```

**VIDEO (Flow / Veo)**
```
Slow pan right: เต้กำลังแขวนซองมาม่าขึ้นผนังเพ็กบอร์ดอย่างตั้งใจ ร้านคึกคัก ลูกค้านั่งเต็มโต๊ะ
อารมณ์: ตั้งใจทำงาน อารมณ์ดี, เสียงบรรยากาศ: เสียงคนคุยกัน เสียงน้ำเดือดในหม้อ
```
