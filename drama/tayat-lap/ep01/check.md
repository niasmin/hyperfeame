# EP.1 — เช็กลิสต์ก่อนกดเจน

- [x] ทุกช็อตมี identity block ของตัวละครคำต่อคำ และระบุรูปที่ต้องแนบ (คอลัมน์ "แนบ")
- [x] แต่ละช็อตมีการกระทำเดียว และกล้องขยับอย่างมากหนึ่งแบบ (แก้ช็อต 8, 11, 12 ให้เหลือการกระทำเดียวแล้ว)
- [x] บทพูดยาวที่สุดประมาณ 12 พยางค์ (ช็อต 3) ≈ 3 วินาที — พอดีกับช็อต 8–10 วินาที ไม่มีบรรทัดไหนยาวเกิน
- [x] ขนาดภาพสลับกัน: CU → WS → MS → FS → OTS → CU → MCU → MS → CU → ECU → MFS → MS (ไม่มีขนาดเดียวกันติดกันเกิน 1 ช็อต)
- [x] ฉากคุยกันใช้ OTS (ช็อต 5) และสลับหน้า (ช็อต 6/7, 8/9)
- [x] voice line ของแต่ละตัวละครเหมือนกันทุกช็อต
- [x] ทุก VIDEO prompt จบด้วย "ไม่มีเพลง ไม่มีข้อความ ไม่มีซับไตเติล ไม่มีเอฟเฟกต์ ไม่มีกราฟิก ไม่มีการตัดต่อ"
- [x] ช็อต 1 เป็นฮุกที่อารมณ์แรงที่สุด; ช็อต 12 จบด้วยปมที่ยังไม่เฉลย
- [ ] **ประเมินเครดิต:** ต่อตอน = รูปอ้างอิง 4–5 แผ่น (ครั้งเดียวทั้งซีรีส์) + ภาพ 12 ภาพ + วิดีโอ 12 คลิป (+ เผื่อเจนซ้ำ ~20%) — ใส่ราคาต่อคลิปของแพ็กที่ใช้อยู่ แล้วผมคำนวณให้

**จุดเสี่ยงที่ควรระวังตอนเจน**
- ช็อต 1: ซุปบนหน้า/ชุดอาจออกมาดูปลอม — ถ้าไม่เนียน ลดเหลือแค่คราบบนผ้ากันเปื้อน
- ช็อต 7: ชามไถลตก (ฟิสิกส์) เจนยาก — ถ้าพลาด 2 ครั้ง เปลี่ยนเป็น "ผลักชามเบาๆ ไปทางฝน" แล้วใช้เสียงชามแตกใส่ใน CapCut
- ช็อต 8, 12: มีสองคนในช็อต — แนบรูปอ้างอิงทั้งสองคน และเจนภาพนิ่งให้ถูกก่อนค่อยทำวิดีโอ
