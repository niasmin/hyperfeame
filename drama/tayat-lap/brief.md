# ทายาทลับ ร้านมาม่า — Brief

**Logline:** หนุ่มล้างจานร้านมาม่าในห้างที่โดนผู้จัดการห้างดูถูกทุกวัน ที่จริงคือหลานชายคนเดียวของเจ้าของห้าง ที่ปลอมตัวมาเรียนรู้ชีวิตจริงก่อนรับมรดก

| | |
| --- | --- |
| แนว | ซ่อนตัวตน (hidden heir) + โรแมนติกคอมเมดี้ + แก้แค้นสายสะใจ |
| โทน | สนุก สะใจ อบอุ่น ไม่ดราม่าหนัก |
| คนดู | วัยรุ่น–วัยทำงาน 18–35 ที่ดูซีรีส์สั้นบน TikTok / Reels |
| จำนวนตอน | 5 ตอน ตอนละ ~2 นาที (12 ช็อต × ~10 วินาที) |
| สัดส่วน | แนวตั้ง 9:16 |
| ลุค | ถ่ายจริงสไตล์กล้อง DSLR, ร้านโทนแดง-เหลือง (สีแบรนด์มากิน มาม่า), ห้องผู้บริหารโทนเทา-ทองเย็นตา |
| เสียง | ตัวละครพูดไทย, ไม่มีเพลงในคลิปที่เจน (ใส่ใน CapCut) |
| ฉากร้าน | ร้าน "มากิน มาม่า" สาขาในห้าง — เปลี่ยนชื่อได้ |

## เรื่องย่อ 5 ตอน

| ตอน | ชื่อตอน | เกิดอะไรขึ้น | ปมท้ายตอน |
| --- | --- | --- | --- |
| 1 | ลูกค้าวีไอพี | เจมส์ ผู้จัดการห้าง บุกร้าน ปัดชามมาม่าใส่ฝน ขู่ยกเลิกสัญญาเช่าใน 7 วัน เต้ยืนขวาง | เลขาฯ มาโค้งเต้ที่ประตูหลังห้าง: "คุณชายคะ ท่านประธานเรียกพบด่วนค่ะ" |
| 2 | นาฬิกาเรือนนั้น | ฝนเห็นเต้ขึ้นรถหรู แต่เต้แก้ตัวว่าเป็นรถลูกค้า ฝนเจอนาฬิกาแพงในล็อกเกอร์เต้ | ฝนเปิดกล่องนาฬิกา เจอรูปเด็กกับคุณปู่หน้าห้าง |
| 3 | สัญญาปลอม | เต้แอบตรวจเอกสาร พบว่าเจมส์ปลอมสัญญาเช่าเพื่อเอาพื้นที่ให้แบรนด์ของตัวเอง | เจมส์เห็นเต้ในห้องเอกสาร: "แกเป็นใครกันแน่" |
| 4 | วันปิดร้าน | ครบ 7 วัน ร้านโดนสั่งปิด ฝนรู้ว่าเต้โกหกเรื่องตัวตน รู้สึกโดนหลอก | ฝนยื่นใบลาออกแล้วเดินจากไป เต้รับโทรศัพท์: "ประชุมบอร์ดพรุ่งนี้ 9 โมง" |
| 5 | ทายาทตัวจริง | ประชุมบอร์ด เต้เปิดตัวเป็นทายาท เปิดโปงเจมส์ ร้านได้สัญญาใหม่ เต้ไปขอโทษฝนที่ร้าน | ฝนยิ้ม: "งั้นคุณชายล้างจานต่อได้ไหมคะ" + ทีเซอร์ซีซัน 2 |
